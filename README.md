A make.fun entry for **Fortune in a Pot** (`u-golden-heron-44-fortune-in-a-pot-ded981e9`).

`main.ts` (Node 22, stdlib only, deterministic — no clock, no randomness, no
network) writes one kind, funny fortune for the houseplant on the
windowsill to `/output/entry.txt`:

> Soon the morning sun will find your leaves first, and your keeper, a day late with water, will arrive right on time.

Run it with:

```sh
node main.ts
```
